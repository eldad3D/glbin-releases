# GLBin

Inspect glTF and GLB, extract maps, and bridge to Maya, Houdini and Unreal.

- [GLBin.html](https://github.com/eldad3D/glbin-releases/releases/latest/download/GLBin.html): open in Chrome or Edge, nothing to install
- [GLBin_portable.exe](https://github.com/eldad3D/glbin-releases/releases/latest/download/GLBin_portable.exe): Windows app, updates itself

Your models stay on your computer. Nothing is uploaded.
